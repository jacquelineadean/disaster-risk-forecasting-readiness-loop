Guided demos
01The walkthrough, command by command

The commands from the walkthrough, run here. Pick a contract; the output lands in the terminal.

The loop writes into a fresh experiments tree, so the ledger starts empty like a new clone's; switch to the committed tree in the terminal's toolbar to append to a copy of the real ledgers instead. Scoring against test without --spend-test-touch is refused, as it should be.

        03Calibration playground
        

          
Fit a proposable model on the training years, pass its forecasts through a monotone recalibration — q = σ(scale · logit(p) + shift) — and re-score with the real harness: scorecard, contract verdict, canary. The seasonal climatology on tornado-ok fails one clause; see whether you can make it pass, and what the canary says when you pick the oracle.

What is on board

        

      

    

  






  
The sandbox runs Pyodide, CPython compiled to WebAssembly, loaded from cdn.jsdelivr.net. The package itself has no dependencies, which is why it fits. Commands that need the network (snapshot) or a process (mcp, report) are not available here.
